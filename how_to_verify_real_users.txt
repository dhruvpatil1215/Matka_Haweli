================================================================================
HOW TO VERIFY REAL CUSTOMERS & PREVENT FAKE ORDERS
================================================================================

If you are running an online restaurant like Matka Haweli, scammers might place fake 
orders (e.g. cash on delivery or takeaway) using fake names and numbers. 

Here are the best ways to verify that a customer is real, how to implement them,
and their pros/cons.

--------------------------------------------------------------------------------
METHOD 1: SMS OTP (One-Time Password)
--------------------------------------------------------------------------------
When a customer clicks "Order Now", they receive a 4 or 6-digit code on their phone.
They must type this code into your website to finish placing the order.

* How to implement:
  - You can use Firebase Authentication (Phone Auth) which gives 10,000 free SMS/month.
  - Or you can use SMS APIs popular in India like Msg91, Twilio Verify, or Fast2SMS.
* Pros: 
  - 100% Scam proof. No one can place an order without a real, working SIM card.
* Cons:
  - If using paid SMS services, there is a cost per SMS sent.
  - Adds a small step for the user, which might slightly reduce conversion rates.

--------------------------------------------------------------------------------
METHOD 2: WhatsApp OTP / Chatbot Confirmation
--------------------------------------------------------------------------------
Since almost everyone in India uses WhatsApp, you can verify users via WhatsApp.

* How to implement:
  - Setup a WhatsApp Cloud API account (via Meta) or use a third-party service like 
    Wati.io or Aisensy.
  - Option A (OTP): Send the 6-digit code via WhatsApp instead of SMS.
  - Option B (Automated confirmation): When an order is placed, an automated message 
    is sent to their WhatsApp: "Hi, did you place this order? Reply YES to confirm."
* Pros:
  - WhatsApp messages are highly trusted and read immediately.
  - Often cheaper than SMS verifications.
* Cons:
  - Requires setting up a WhatsApp Business API account.

--------------------------------------------------------------------------------
METHOD 3: Frontend Phone Format Check (Regex)
--------------------------------------------------------------------------------
A simple client-side check to verify the format of the number before they can click
the order button.

* How to implement in React:
  - Add validation using a Regular Expression (Regex) to ensure the number starts with
    6, 7, 8, or 9 and is exactly 10 digits.
  - Example React check:
    const isValidPhone = /^[6-9]\d{9}$/.test(phoneNumber);
* Pros:
  - Free and instant setup.
  - Blocks obviously fake numbers like "12345", "99999999", or alphabets.
* Cons:
  - Does NOT stop scammers who enter someone else's real 10-digit phone number.

--------------------------------------------------------------------------------
METHOD 4: Rate Limiting & CAPTCHA
--------------------------------------------------------------------------------
Prevents automatic bots or competitors from sending hundreds of fake orders.

* How to implement:
  - Add Google reCAPTCHA v3 (invisible) to the checkout button.
  - Track IP address in your database when an order is placed and block an IP 
    if it attempts to make more than 3 orders in 1 hour.
* Pros:
  - Blocks automated bot scripts completely.
* Cons:
  - Does not stop manual human scammers.

================================================================================
SUMMARY RECOMMENDATION FOR MATKA HAWELI:
================================================================================
1. Start with Method 3 (Regex formatting) to filter out typos and lazy fakes.
2. If you are getting a lot of fake cash-on-delivery or takeaway orders, implement 
   Method 1 (SMS OTP via Firebase) because it has 10,000 free verifications per month,
   which is more than enough for a local restaurant's monthly order volume.
